# 🗡️ Подземелье Великих (Dungeon of the Greatest)

Пошаговая текстовая ролевая игра (RPG) с элементами roguelike, разработанная на языке Python с использованием библиотеки Tkinter для создания графического интерфейса.

## 📋 Описание

«Подземелье Великих» — это курсовой проект по дисциплине «Технологии прикладного программирования». Игра представляет собой текстовую RPG с процедурной генерацией подземелий, пошаговой боевой системой и разнообразными игровыми механиками.

Исследуйте мрачные подземелья, сражайтесь с монстрами, находите сокровища и победите Крылатого Демона на 100-й комнате!

## ✨ Особенности

- **7 уникальных классов персонажей** с различными характеристиками и стартовым снаряжением
- **Пошаговая боевая система** с возможностью атаки, защиты и использования классовых способностей
- **Процедурная генерация событий**: случайные бои, сундуки с лутом, ловушки, NPC и уникальные ситуации
- **Система ресурсов**: управление здоровьем (HP), выносливостью (Stamina) и маной (Mana)
- **Ограниченный инвентарь** с возможностью выбрасывания предметов
- **Городской хаб** с локациями:
  - 🍺 Таверна (отдых, сплетни, азартные игры)
  - 🕊️ Монастырь (восстановление маны)
  - 🛒 Лавка (покупка предметов и снаряжения)
  - 📜 Гильдия (прокачка характеристик)
  - 🎪 Шатёр Барда (уникальные бонусы)
- **Босс на 100-й комнате**: Крылатый Демон с уникальными атаками и механиками
- **Текстовый ASCII-арт** для визуализации локаций и врагов
