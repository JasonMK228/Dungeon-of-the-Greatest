# ⚔️ Dungeon of the Greatest: Пошаговое RPG
Текстовая ролевая игра в стиле Darkest Dungeon, написанная на Python с использованием библиотеки Tkinter.

##  О проекте
Проект представляет собой реализацию игровой архитектуры (State Machine, Event System) без использования сторонних игровых движков. Акцент сделан на модульности кода, алгоритмах боя и процедурной генерации событий.

## 🚀 Особенности
- **Пошаговая боевая система:** Расчет урона, защита, стамина, критические удары.
- **Управление ресурсами:** HP, Стамина, Мана (для магов/паладинов), Золото.
- **Городской хаб:** Таверна, Алхимик, Кузница, Гильдия, Монастырь.
- **Система лута:** Сундуки с рандомным дропом, инвентарь.
- **Классовая уникальность:** 6 классов с разными статами и способностями.
- **Сохранение/Загрузка:** Сериализация состояния через JSON.

## 🏗️ Архитектура
Проект разделен на модули для удобства поддержки:
- `main.py`: Игровой цикл, UI (Tkinter), управление состояниями.
- `ClassHero.py`: Классы героев, шаблоны статов.
- `Enemy_DB.py`: База данных врагов.
- `ASC_Sprites.py`: Визуальное оформление (ASCII-арт).
